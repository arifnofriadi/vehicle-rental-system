# Aplikasi Rental Kendaraan — UAS OOP

Proyek kelompok UAS SI204 Object-Oriented Programming. Skenario: **Aplikasi Rental Kendaraan** (sewa motor, mobil, sepeda listrik).

## Fitur Minimal
- Daftar kendaraan
- Proses sewa
- Proses pengembalian
- Hitung total biaya

## Persyaratan Wajib
- [ ] Enkapsulasi
- [ ] Pewarisan (inheritance) + overriding
- [ ] Polimorfisme
- [ ] Abstract class dan/atau interface
- [ ] Exception handling (input salah / kondisi tidak valid tidak boleh crash)
- [ ] 2 design pattern (pilih dari: Singleton, Factory, Adapter, Decorator, Observer, Strategy) — *belum ditentukan*
- [ ] Diagram kelas UML (taruh di `docs/`)

## Struktur Folder
```
final-exam/
├── src/        # source code Java (.java)
├── docs/       # diagram kelas UML (gambar/PDF)
└── README.md
```

## Build & Run
Compile manual pakai javac (tanpa build tool):
```bash
javac -d bin src/*.java
java -cp bin Main
```
